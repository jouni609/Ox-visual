# OX — Five Faces of the Ox

A single-page showcase of **five distinctly different frontend designs**, each built around the ox and one of its traits. Every design is a complete art direction of its own — palette, typography, hand-drawn SVG artwork and motion language — switchable at runtime from the dock in the bottom-right corner (keys `1`–`5` also work).

This project is focused on **frontend designs generated by agents**: every layout, illustration, color system and animation was authored end-to-end by an AI agent as a demonstration of machine-driven design craft.

## The five faces

| # | Design | Trait | Direction |
|---|--------|-------|-----------|
| 01 | **Monolith** | Raw power | Brutalist black/bone/signal-red, geometric ox head, slam-in type, marquee, count-up stats |
| 02 | **Heritage** | Endurance | Parchment museum-editorial, engraved line-art ox, timeline from 8000 BCE to today |
| 03 | **Circuit Beast** | Relentless drive | Neon wireframe ox on a scrolling synthwave grid, glitch headings, terminal diagnostics |
| 04 | **Stillness** | Patience | Ink-brush ox that draws itself stroke-by-stroke, breathing enso, haiku reveals |
| 05 | **Barnyard Pop** | Friendly diligence | Cartoon ox with cursor-following eyes, wiggling ears, springy sticker badges |

## Tech stack

- [Vite](https://vitejs.dev/) + [React](https://react.dev/)
- [Framer Motion](https://www.framer.com/motion/) for springs, scroll reveals and crossfade transitions
- Hand-written CSS per theme (no UI framework) + inline SVG artwork drawn in code
- Google Fonts

## Run it

```bash
npm install
npm run dev
```

Then open the printed local URL. Production build:

```bash
npm run build
npm run preview
```
